# Project Documentation

This directory contains the official technical documentation and supporting documents for the **Smart Traffic Monitoring System**.

## Contents

| File | Description |
|---|---|
| `Manual_Report.pdf` | Complete project report covering the system overview, design, implementation, hardware, software, and testing. |
| `Bill_Of_Materials.xlsx` | Detailed Bill of Materials (BOM), including the electronic components, quantities, and other required hardware items. |

## Purpose

The documents provide a comprehensive reference for understanding the project's design, hardware requirements, implementation, and technical specifications.

## Project

**Smart Traffic Monitoring System 🚦**

An IoT-based traffic monitoring solution developed using ESP32 to monitor vehicle movement, manage traffic signals, and detect red-light violations.
